## Timing and comparison

Give comparable sample sizes and observed elapsed time. Separate agent-work totals from
wall time, include retries/interruption context, and leave unmeasured gaps unknown.

## Changes and validation

Record what changed, the affected tests or scenario review, and evidence reused. For a
read-only audit, list recommendations without implying that changes were applied.

## Next comparable run

Name the expected improvement signal and the quality evidence to retain. State what
would support keeping, adjusting, or reversing the change. No measured benefit yet
means the improvement remains a hypothesis.
